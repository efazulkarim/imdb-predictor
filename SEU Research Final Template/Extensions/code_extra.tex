\chapter{Code Listings for IMDb Rating Prediction}

This appendix provides the complete Python implementation of key components of the IMDb rating prediction system. The system uses SBERT (Sentence Transformer) for semantic text embedding and XGBoost for regression.

\section{SBERT Embedding Generation}

Code listing~\ref{code:sbert_embedding} shows the implementation of the SBERT embedding generation with chunking strategy. This module handles long movie scripts by dividing them into overlapping chunks and averaging the resulting embeddings.

\lstinputlisting[
    language=Python,
    caption={SBERT Embedding Generation with Chunking Strategy},
    label={code:sbert_embedding}
]{Codes/sbert_embedding.py}

Key features of this implementation:

\begin{itemize}
    \item \textbf{Chunking Strategy}: Scripts are split into 256-word chunks with 50-word overlap to maintain context
    \item \textbf{Average Pooling}: Multiple chunk embeddings are averaged to produce a single document-level representation
    \item \textbf{Fixed Dimension}: Output is always a 384-dimensional vector (all-MiniLM-L6-v2)
    \item \textbf{Scalable}: Can handle scripts of any length by chunking
\end{itemize}

The function \texttt{generate\_sbert\_embedding} takes a movie script text and returns a 384-dimensional embedding vector that captures semantic information about the script's content.

\section{XGBoost Model Training}

Code listing~\ref{code:xgboost_trainer} presents the complete XGBoost training pipeline. This module implements the full training process including data splitting, feature engineering, sample weighting for class balancing, and model evaluation.

\lstinputlisting[
    language=Python,
    caption={XGBoost Training Pipeline with Class Balancing},
    label={code:xgboost_trainer}
]{Codes/xgboost_trainer.py}

Key components of this implementation:

\begin{itemize}
    \item \textbf{Class Balancing}: Sample weights are computed inversely to class frequency to handle imbalanced rating distribution (fewer excellent/terrible movies)
    \item \textbf{Data Split}: 70\% training / 15\% validation / 15\% test with consistent random state (42)
    \item \textbf{Feature Scaling}: StandardScaler normalizes numerical features to have zero mean and unit variance
    \item \textbf{Feature Combination}: SBERT embeddings (384-dim) are concatenated with numerical features (19-dim) for 403 total features
    \item \textbf{Evaluation}: Comprehensive metrics including RMSE, MAE, and R$^2$ score on both validation and test sets
\end{itemize}

\section{Dependencies}

The system requires the following Python packages:

\begin{itemize}
    \item \texttt{sentence-transformers} $\ge$ 2.2.0 - SBERT model loading
    \item \texttt{torch} $\ge$ 2.0.0 - PyTorch backend for transformers
    \item \texttt{xgboost} == 2.0.2 - Gradient boosting implementation
    \item \texttt{scikit-learn} == 1.3.2 - Preprocessing and metrics
    \item \texttt{pandas} == 2.1.3 - Data manipulation
    \item \texttt{numpy} == 1.26.2 - Numerical computations
    \item \texttt{openpyxl} == 3.1.2 - Excel file reading
\end{itemize}

All dependencies can be installed using:
\begin{lstlisting}[language=bash, caption={Installation Command}]
pip install -r requirements.txt
\end{lstlisting}
