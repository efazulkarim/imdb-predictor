\section{How to use this template}
\begin{enumerate}
    \item Open an account in \href{www.overleaf.com}{www.overleaf.com}
    \item To practice and understand how the template works, go to new project-->upload project and up ``SEU\_Research\_Final\_Template.zip'' file
    \item Go through main.tex to see how the files are structured. 
    \item In parallel, read the given ``SEU\_Research\_Final\_Template.zip.pdf'' and try to tune and change the commands.
    \item After you get used to the template, you can start editing the template.
    \item Start working on your research and contact us for any problem you are facing regarding this template.
\end{enumerate}
